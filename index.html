05 / PROCESS

From idea

Start with the problem.

Define what the project is actually supposed to accomplish before writing unnecessary code.

PHASE 02 / SYSTEM

Build the foundation.

Structure the code, interface and components so the project can grow without becoming impossible to maintain.

PHASE 03 / DESIGN

Make it feel intentional.

Refine interaction, motion, spacing, typography, composition and visual hierarchy.

PHASE 04 / RELEASE

Ship it.

Test the result, remove unnecessary complexity and put the finished project where people can actually use it.
